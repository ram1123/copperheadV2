# Compare v9, v12, and v15 NanoAODs

To compare the distributions of variables in the v9, v12, and v15 NanoAODs, where input files are `.root` files having nonoAOD format, use the script [compare_v9v12_simple_fast_ratio.py](compare_v9v12_simple_fast_ratio.py) or [compare_v9v12_simple_fast_diff.py](compare_v9v12_simple_fast_diff.py).

It uses the config file [config/plot_config_nanoV12vsV9.yaml](config/plot_config_nanoV12vsV9.yaml) to specify the input files and other settings.
