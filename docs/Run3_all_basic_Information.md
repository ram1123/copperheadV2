# Run3 HMuMu synchronization Purdue

## Object Selection

### Muon Selection & Corrections

| Object              | Selection / Correction Criterion                                                   |
| ------------------- | ---------------------------------------------------------------------------------- |
| **Muon**            | Beam-spot corrected muon _(revert to default if beam-spot $\chi^2 \geq 30$)_       |
| -                   | Rochester correction _(beam-spot–specific calibration unavailable)_                |
| -                   | At least one muon matched to fired trigger: pₜ > 26(29) GeV for 2016 & 2018 (2017) |
| -                   | Exactly 2 muons, both with $p_T$ > 20 GeV and opposite charge                      |
| -                   | $abs(\eta)$ < 2.4                                                                  |
| -                   | Pass Medium ID and loose PF isolation                                              |
| -                   | Number of good primary vertices > 0                                                |
| -                   | FSR recovery                                                                       |
| Filters/Corrections | Correction order: Beam-spot → Rochester → FSR                                      |

### Electron Selection

| Object       | Selection / Correction Criterion                      |
| ------------ | ----------------------------------------------------- |
| **Electron** | $p_T >$ 20 GeV and $abs(\eta) < 2.5$                  |
| -            | Ignore electrons in 1.44 < $abs(\eta)$ < 1.57         |
| -            | Pass WP90 MVA-based ID                                |
| -            | Veto events with electrons passing this pre-selection |

### Jet Selection & Corrections

| Object              | Selection / Correction Criterion                                |
| ------------------- | --------------------------------------------------------------- |
| **Jet**             | AK4 PUPPI jets with $p_T > 25$ GeV and $abs(\eta) < 4.7$        |
| -                   | Tight jet ID for all years (loose ID not available for 2016 UL) |
| -                   | Clean from selected muons                                       |
| B-tag               | B-tag: pass jet pre-selection and $abs(\eta) < 2.5$             |
| B-tag               | B-tag: use loose and medium DeepCSV working points              |
| Filters/Corrections | Event veto in jet HEM region for 2018 (~5% yield removed)       |
